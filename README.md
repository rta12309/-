# 멀티체인 지갑 그룹 뷰어

설치 없이 `index.html` 파일을 브라우저에서 바로 열면 실행됩니다.

## 기능
- 그룹 추가/삭제
- 그룹 내 지갑 주소 행 추가/삭제
- 체인 선택 + 지갑 주소 입력
- 스캔 URL 자동 연결
  - 주소가 유효하면 해당 지갑의 주소 페이지
  - 주소가 비어있거나 잘못되면 스캔 메인 페이지
- 업비트 KRW-USDT 기준 환율 적용
- KRW를 억 단위(소수점 2자리)로 표시
- 주요 체인(Ethereum, BNB, Base, Arbitrum, Optimism, Polygon, Avalanche, Solana) 조회

## 실행 방법
1. `index.html`을 더블클릭해서 브라우저에서 엽니다.
2. 그룹/지갑을 추가하고 체인과 지갑 주소를 입력합니다.
3. `자산 조회` 또는 `전체 새로고침` 버튼을 누릅니다.

## 참고
- EVM 체인의 토큰은 각 스캔 API의 `tokenlist` 응답 기준으로 표시합니다.
- 일부 체인은 브라우저 CORS/API 제한으로 조회가 실패할 수 있습니다.
