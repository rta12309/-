# om가격차 모니터링 (코딩템플릿1 / 웹사이트 버전)

업비트(KRW-OM), 빗썸(OM_KRW), 바이낸스 선물(OMUSDT)을 비교해서
가격 차이가 임계값(기본 5%) 이상일 때 웹/텔레그램 알림을 주는 로컬 웹앱입니다.

## 1) 초보자용 실행 방법 (Windows)
1. 이 폴더를 엽니다.
2. `RUN_WINDOWS.bat` 파일을 더블클릭합니다.
3. 처음 실행 시 필요한 패키지 설치 후 브라우저가 열립니다.
4. 화면에서 임계값/주기/쿨다운을 확인하고 `[시작]` 버튼을 누릅니다.

## 2) 초보자용 실행 방법 (macOS / Linux)
1. 터미널에서 이 폴더로 이동합니다.
2. 아래 명령 실행:
   ```bash
   ./RUN_MAC_LINUX.sh
   ```
   (macOS Finder 더블클릭용은 `RUN_MAC.command` 사용 가능)
3. 브라우저에서 `http://127.0.0.1:8000` 접속 후 `[시작]` 클릭.

## 3) 수동 실행 방법
```bash
python -m pip install -r requirements.txt
python app.py
```
(또는 `python3`)

## 4) 화면에서 할 수 있는 것
- `[시작] / [중지]` 버튼
- 임계값(%), 조회주기(초), 쿨다운(초) 입력
- 웹 알림 ON/OFF, 텔레그램 ON/OFF
- "바이낸스 선물가가 더 낮으면 알림 제외" 토글
- 텔레그램 Bot Token / Chat ID 입력
- 웹 알림 테스트 / 텔레그램 테스트 버튼
- 실시간 가격표 + 3개 비교쌍 diff% 확인
- 에러 로그 영역에서 API 실패 메시지 확인

## 5) API 요약
- `GET /api/prices`: 현재 가격/환산/차이% JSON
- `POST /api/start`: 모니터링 상태/옵션 시작
- `POST /api/stop`: 모니터링 중지
- `POST /api/test_alert`: 테스트 알림(텔레그램)

## 6) 참고/주의
- 바이낸스 선물 OMUSDT는 USDT 가격이므로 업비트 KRW-USDT로 KRW 환산해서 비교합니다.
- 외부 거래소 API는 일시적으로 실패할 수 있어 timeout/재시도(가벼운 수준)를 넣었습니다.
- 기본 조회주기는 5초이며 너무 짧게 설정하지 않는 것을 권장합니다.
