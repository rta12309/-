# Upbit-Bithumb Price Gap Alert

업비트(KRW 마켓)와 빗썸(KRW 마켓)의 동일 코인 가격을 주기적으로 비교해서,
가격 차이가 **5% 이상**이면 콘솔에 경고를 출력하고 알림음을 울리는 앱입니다.

## 기능

- 업비트 전체 KRW 마켓 코인 가격 조회
- 빗썸 전체 KRW 마켓 코인 가격 조회
- 공통 코인 심볼 기준 가격 차이(%) 계산
- 임계값(기본 5%) 이상인 경우 경고 + 알림음
- 주기적 모니터링 (`--interval`)
- 외부 라이브러리 없이 표준 라이브러리만 사용

## 실행

기본값(임계값 5%, 30초 주기):

```bash
python3 app.py
```

임계값/주기 변경:

```bash
python3 app.py --threshold 5 --interval 15
```

## 알림 방식

- Windows: `winsound.Beep()`
- 기타 OS: 터미널 벨 문자(`\a`)

> 참고: 실제 소리 재생 여부는 운영체제/터미널 설정에 따라 다를 수 있습니다.
