# om가격차 모니터링 (웹 전용 버전)

이 버전은 **설치 없이 브라우저에서 HTML 파일만 열어서** 동작합니다.
(백엔드 서버 없이 JS가 거래소 공개 API를 직접 조회)

## 1) 가장 쉬운 실행 방법 (설치 없음)
1. `templates/index.html` 파일을 더블클릭해서 브라우저로 엽니다.
2. 임계값/조회주기/쿨다운을 설정합니다.
3. `[시작]` 버튼을 누릅니다.

## 2) 핵심 기능
- 비교 대상: 업비트(KRW-OM), 빗썸(OM_KRW), 바이낸스 **현물**(OMUSDT, KRW 환산)
- 환산 기준: 업비트 KRW-USDT
- diff 공식: `abs(A - B) / min(A, B) * 100`
- 임계값 초과 시 웹 알림 + (옵션) 텔레그램 알림
- 쿨다운(기본 300초)으로 재알림 간격 제한

## 3) 요청 반영된 안전 버튼
- `바이낸스 현물/선물 차이 2%↑이면 알림 제외` 체크 시,
  바이낸스 현물-선물 괴리율이 2% 이상인 동안은 **웹/텔레그램 알림을 모두 차단**합니다.

## 4) 참고
- 브라우저 CORS/네트워크 정책에 따라 일부 API 요청이 실패할 수 있습니다.
- 텔레그램 전송은 브라우저에서 Bot API를 직접 호출하므로 환경에 따라 차단될 수 있습니다.
