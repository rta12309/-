# 바낸업빗가격차이 알림 (웹 전용 버전)

이 버전은 **설치 없이 브라우저에서 HTML 파일만 열어서** 동작합니다.
(백엔드 서버 없이 JS가 거래소 공개 API를 직접 조회)

## 1) 실행 방법 (설치 없음)
1. `templates/index.html` 파일을 더블클릭해서 브라우저로 엽니다.
2. `업비트 / 빗썸 / 바이낸스 / 바이비트` 티커를 각각 입력합니다.
3. 임계값/조회주기/쿨다운/선물-현물 괴리 차단값(%)을 설정합니다.
4. 필요하면 거래소별 탐색 ON/OFF를 조절합니다.
5. `[시작]` 버튼을 누릅니다.

## 2) 핵심 기능
- 비교 대상: 업비트(KRW-업비트티커), 빗썸(빗썸티커_KRW), 바이낸스 현물(바이낸스티커USDT), 바이비트 현물(바이비트티커USDT)
- 추가 표기: 바이낸스/바이비트 선물 가격 및 선물-현물 괴리율
- 환산 기준: 업비트 KRW-USDT
- diff 공식: `abs(A - B) / min(A, B) * 100`
- 임계값 초과 시 웹 알림 + (옵션) 텔레그램 알림

## 3) 숫자 입력 규칙 (요청 반영)
- 티커 칸에 **문자 대신 숫자**를 넣으면, 그 숫자를 **달러 기준 가격(USDT)** 으로 간주합니다.
- 예: 바이낸스 티커 칸에 `1.23` 입력 시 바이낸스 현물/선물 가격을 1.23 USDT로 사용합니다.
- 업비트/빗썸 티커 칸에 숫자를 넣으면 KRW-USDT 환산을 이용해 KRW 값으로 계산합니다.

## 4) 추가 요청 반영
- 거래소별 티커 입력 분리 + 거래소별 탐색 ON/OFF
- 특정 거래소가 미지원/실패여도 해당 거래소만 비우고 나머지 비교쌍 계속 동작
- 선물/현물 괴리 차단값(%) 사용자 설정 가능

## 5) 참고
- 브라우저 CORS/네트워크 정책에 따라 일부 API 요청이 실패할 수 있습니다.
- 텔레그램 전송은 브라우저에서 Bot API를 직접 호출하므로 환경에 따라 차단될 수 있습니다.
