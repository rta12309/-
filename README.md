# 바낸업빗가격차이 알림 (웹 전용 버전)

이 버전은 **설치 없이 브라우저에서 HTML 파일만 열어서** 동작합니다.
(백엔드 서버 없이 JS가 거래소 공개 API를 직접 조회)

## 1) 실행 방법 (설치 없음)
1. `templates/index.html` 파일을 더블클릭해서 브라우저로 엽니다.
2. `업비트 티커 / 빗썸 티커 / 바이낸스 티커`를 각각 입력합니다.
3. 임계값/조회주기/쿨다운/현물-선물 괴리 차단값(%)을 설정합니다.
4. 필요하면 거래소별 탐색 ON/OFF를 조절합니다.
5. `[시작]` 버튼을 누릅니다.

## 2) 핵심 기능
- 비교 대상: 업비트(KRW-업비트티커), 빗썸(빗썸티커_KRW), 바이낸스 현물(바이낸스티커USDT)
- 환산 기준: 업비트 KRW-USDT
- diff 공식: `abs(A - B) / min(A, B) * 100`
- 임계값 초과 시 웹 알림 + (옵션) 텔레그램 알림
- 쿨다운(기본 300초)으로 재알림 간격 제한

## 3) 추가 요청 반영
- 바이낸스 선물 아래에 `바이낸스 선물-현물 가격차이(%)` 표시 칸 추가
- `현물/선물 괴리 차단값(%)`을 사용자가 직접 변경 가능
- 거래소별 티커가 다른 경우를 대비해, 업비트/빗썸/바이낸스 티커를 각각 따로 입력 가능
- 거래소별 탐색 ON/OFF 지원 (OFF한 거래소는 조회/비교에서 제외)

- 특정 거래소에서 티커를 못 찾으면 해당 거래소 값만 `-`로 표시하고, 가능한 비교쌍만 계속 모니터링

## 4) 참고
- 브라우저 CORS/네트워크 정책에 따라 일부 API 요청이 실패할 수 있습니다.
- 텔레그램 전송은 브라우저에서 Bot API를 직접 호출하므로 환경에 따라 차단될 수 있습니다.
