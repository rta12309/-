# 코딩템플릿1 코인 가격차이 알림기 (Windows 전용) v1.0

업비트와 빗썸의 **공통 코인 전체**를 검사해서,

- 가격차이가 기준(기본 5%) 이상이고
- 해당 코인이 **양 거래소 모두 입출금 가능**할 때만

알림을 주는 초보자용 프로그램입니다.

---

## 1) 준비물

1. Windows PC
2. Python 3.10 이상 설치
3. 인터넷 연결

---

## 2) 설치 방법 (처음 1회)

1. 이 폴더를 다운로드/압축해제합니다.
2. 폴더에서 주소창에 `cmd` 입력 후 엔터를 눌러 명령창을 엽니다.
3. 아래 명령을 실행합니다.

```bash
pip install -r requirements.txt
```

---

## 3) 실행 방법

### A. 데스크톱 GUI 실행

- `RUN_DESKTOP_WINDOWS.bat` 더블클릭
- 또는 명령창에서:

```bash
python app.py
```

### B. 웹 모드 실행 (로컬 웹앱)

- `RUN_WEB_WINDOWS.bat` 더블클릭
- 브라우저가 자동으로 열립니다.
- 직접 접속 주소: `http://127.0.0.1:5000`

---

## 4) 사용 방법

### 공통 기본값

- 알림 기준(%): `5.0`
- 자동 검사 주기(초): `30`

### 버튼 설명

- **1회 검사**: 현재 조건으로 한 번만 검사
- **자동 시작**: 주기적으로 반복 검사
- **자동 중지**: 자동 검사 중단
- **오류 복사**: 오류 로그를 복사

---

## 5) 알림 조건 (중요)

아래 조건을 모두 만족할 때만 알림이 울립니다.

1. 업비트/빗썸 공통 코인
2. 양 거래소 모두 입출금 가능
3. 가격차이(%)가 알림 기준 이상

> 입출금이 막힌 코인은 가격차이가 커도 알림 대상에서 제외됩니다.

---

## 6) 오류가 났을 때

- 화면 하단(또는 웹 오류 영역)에 오류 로그가 표시됩니다.
- **오류 복사** 버튼으로 복사 후 그대로 전달하면 됩니다.

---

## 7) 파일 구성

- `app.py` : 메인 실행 파일 (데스크톱 GUI + 웹 서버 분리 구조)
- `RUN_DESKTOP_WINDOWS.bat` : 데스크톱 모드 실행
- `RUN_WEB_WINDOWS.bat` : 웹 모드 실행
- `requirements.txt` : 필요한 패키지 목록
