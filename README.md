# 업비트-빗썸 가격 차이 알림기

업비트와 빗썸에서 **같은 코인 가격 차이(%)**를 비교해서, 기준값(기본 5%) 이상일 때 팝업 알림을 주는 데스크톱 프로그램입니다.

## 기능
- 업비트/빗썸 공통 KRW 마켓 코인 자동 탐색
- 가격 차이(%) 실시간 모니터링
- 기준값 이상 시 팝업 + 소리 알림
- 입출금 가능 여부 표시
  - 업비트: 지갑 상태
  - 빗썸: 입금/출금 상태
- **입출금 불가능 코인 알림 끄기** 옵션 제공 (체크박스)
- 텔레그램 알림 지원
  - 봇 토큰 / 챗 ID 입력칸 제공
  - 연결 테스트 버튼 제공

## 실행 방법
1. Python 3.10+ 설치
2. 프로그램 실행

```bash
python app.py
```

## 사용법
1. 프로그램을 실행하고 `모니터링 시작` 버튼을 클릭합니다.
2. `가격차이 기준(%)`을 원하는 값으로 설정합니다. (기본 5)
3. `입출금 불가능한 코인은 알림 끄기` 체크 시, 입출금 불가능 코인은 알림에서 제외됩니다.
4. 텔레그램 알림을 받으려면 `봇 토큰`, `챗 ID`를 입력하고 `연결 테스트`를 눌러 확인합니다.
5. 중지하려면 `모니터링 중지` 버튼을 클릭합니다.

## 참고
- 401/403 등 API 오류를 더 명확히 확인할 수 있도록 HTTP 상태 코드와 일부 응답 내용을 상태 메시지로 표시합니다.
- 동일 코인 알림은 과도한 반복을 막기 위해 쿨다운(기본 120초)이 적용됩니다.
